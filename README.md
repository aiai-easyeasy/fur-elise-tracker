# 垃圾車在哪

臺北市 12 個行政區的垃圾車收運點地圖：查離你最近的收運點、幾點會來、整台車當天的行駛順序。

整頁地圖、路名和收運資料都包在網頁裡，載入過一次之後不用網路也能查，只有「定位」本身需要開手機的定位服務。

> 專案名稱取自台灣垃圾車播放的〈給愛麗絲〉（Für Elise）。

## 使用

1. 網址：`https://aiai-easyeasy.github.io/fur-elise-tracker/`
2. 手機開啟後 **分享 → 加入主畫面**，用起來就像 App

第一次開啟會詢問位置；允許過之後再開會自動定位，拒絕過則不會再問（可隨時按右下角「定位」）。

## 怎麼用

- **距離排序**：清單依距離列出最近的收運點。還沒定位或拒絕定位時，改成以地圖目前顯示的中心點起算，拖動地圖就會重新排序。
- **只看還沒來的**：清單預設只顯示今天還沒來、而且今天有收運的班次；已經過去的時段和今天不收的點會先隱藏。想看完整時刻表按清單上方的「顯示全部」。
- **時間自動更新**：「還有幾分鐘」每分鐘自己重算，把手機從背景切回來也會立刻校正，不用重新整理頁面。
- **搜尋**：右上角可以搜尋街名、巷弄，或直接打收運點的名稱。
- **收運點詳情**：點一個點，看時段、路線、車次、車號，以及前後站的順序；按「路線」會在地圖上畫出這台車當天完整的行駛順序。
- **只在特定星期收運的點**：這類站的名稱會註明星期（例如「週一、週五收運」），點開時只列出同一收運日的站序，不是今天收的會標「今天不收」。
- **休息日**：台北市垃圾車週三、週日不收運，這兩天一開啟就會顯示「今日不收運」。
- **深夜**：附近班次都跑完時，畫面會改顯示明天的時刻表，不會變成空白。
- 畫面淺色／深色會跟著手機系統設定切換。

## 使用上請注意

- 原始資料**沒有標記星期**，除了少數寫在地點名稱裡的班次，沒辦法判斷「今天」到底收不收，也分不出一般垃圾、資源回收、廚餘。
- 手機定位在市區常有 20–100 公尺誤差，收運點之間有時候不到 50 公尺，「最近的點」請當參考，抵達前留意實際狀況。
- 士林仰德大道、北投竹子湖路一帶位於山區，座標無法核對，頁面上會標示「可能有誤」。
- 有 3 個地址在原始資料裡本身位置就標錯，兩筆座標相差 200 公尺到 1.8 公里；因為無法判斷哪一筆才對，這幾個地址目前會顯示成兩個分開的點。
- 這份地圖是某個時間點的資料快照，之後的收運路線異動不會自動更新進來。
